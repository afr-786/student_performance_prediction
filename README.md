# Student Performance Prediction using Machine Learning

## Project Overview
This project predicts student exam scores based on study hours, sleep hours, attendance percentage, and previous scores.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Machine Learning Algorithm
Linear Regression

## Model Performance
- Mean Absolute Error: 2.31
- R2 Score: 0.8537

## Sample Prediction
Predicted Exam Score: 37.15

## Project Workflow
1. Dataset Collection
2. Data Loading
3. Data Training and Testing
4. Model Building
5. Score Prediction
6. Graph Visualization
